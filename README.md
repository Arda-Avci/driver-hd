Arcade street racing in the browser, NFS Heat style: the same game as
[Driver](https://arda-avci.github.io/driver/), with detailed car art (rims, head- and taillights,
grilles and side liveries).

**Play:** https://arda-avci.github.io/driver-hd/

Controls: W/↑ throttle · S/↓ brake/reverse · A D / ← → steer · Space handbrake (drift) · Shift nitro ·
hold R reset car · Esc pause · M mute · 1 2 3 time of day. Touch controls on phones.

This repository holds the built site only.
